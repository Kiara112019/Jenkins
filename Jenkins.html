Step-by-Step Guide for Jenkins Step 1: Install Java (Mandatory) Jenkins requires Java. Check Java java -version If not installed, install Java 11 or 17. Step 2: Install Jenkins On Windows Go to Jenkins official site Download Jenkins.msi Double-click the file Click Next → Install Finish installation Jenkins runs automatically after installation. Step 3: Unlock Jenkins (First Time Login) Jenkins asks for Initial Admin Password. Password Location: Windows C:\Program Files (x86)\Jenkins\secrets\initialAdminPassword Linux / macOS /var/lib/jenkins/secrets/initialAdminPassword ➡ Copy the password ➡ Paste it on Jenkins page ➡ Click Continue Step 4: Install Plugins You will see 2 options: Install Suggested Plugins (Recommended) Select plugins manually Choose Install Suggested Plugins Jenkins installs required plugins automatically. Step 5: Create Admin User Fill details: Username Password Full name Email Click Save and Continue Step 6: Jenkins URL Confirmation Default URL: http://localhost:8080/ Click Save and Finish Step 7: Jenkins Dashboard You will now see the Jenkins Dashboard Login is successful. Step 8: Create Your First Job Click New Item Enter Job name Select Freestyle Project Click OK Add build steps Click Save Step 9: Run the Job Click Build Now Check Console Output
